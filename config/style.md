# Digest style (Thai only)
- 3-4 items, ordered 2026 -> 2025 -> older. Max 1 foundational item (tag ความรู้พื้นฐาน).
- Per item: short title, year tag, 2-4 bullets with **bold** key facts/numbers, block "จุดสำคัญที่ควรจำ / Keyword", source line (name + URL + date).
- Simple, scannable. Never invent news; drop any item lacking URL+date.
