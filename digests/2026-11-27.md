## 1. รัฐบาลไทยอนุมัติโครงการพลังงานแสงอาทิตย์บนหลังคา 50 พันล้านบาท `2026`
- การสนับสนุนค่าอุปกรณ์ **50,000 บาทต่อครัวเรือน** เพื่อให้ **หนึ่งล้านครัวเรือน** ติดตั้งแผงโซลาร์เซลล์ภายใน 1 ปี  
- โครงการรวมงบประมาณ **>20 พันล้านบาท** สำหรับการพัฒนา **สมาร์ทกริด** เพื่อรับพลังงานส่วนเกิน  
- การให้เงินตรงจุดช่วยลดค่าไฟฟ้าและเพิ่ม **รายได้จากการขายไฟฟ้าส่วนเกิน** ให้กับครัวเรือน  
- **หลักการ:** ส่งเสริมการใช้พลังงานสะอาดโดยให้ผู้บริโภคเป็นผู้ผลิตไฟฟ้า (prosumer) ลดการพึ่งพานำเข้าน้ำมันและก๊าซธรรมชาติ  
- **ผลกระทบ/ประโยชน์:** ลดค่าใช้จ่ายพลังงานของประชาชน เพิ่มอัตราการใช้พลังงานทดแทน และกระตุ้นอุตสาหกรรมอุปกรณ์แสงอาทิตย์ในประเทศ  

> **จุดสำคัญที่ควรจำ / Keyword:** Rooftop solar → 50 bn THB, 1 M households, smart grid

## 2. การปล่อยจรวด THEOS‑2A ของไทยล้มเหลวไม่เข้าสู่วงโคจร `2026`
- จรวด **PSLV** จาก ISRO ประสบปัญหาในขั้นตอน **ขั้นที่ 3** ทำให้ดาวเทียม 100 kg ไม่ถึงวงโคจรที่กำหนด  
- THEOS‑2A ถือเป็นดาวเทียมสังเกตการณ์พื้นผิวแรกที่พัฒนาโดยวิศวกรไทย **20 คน** ใช้วัสดุระดับอุตสาหกรรม  
- แม้ไม่สำเร็จ ภารกิจยังคงมุ่งให้ข้อมูลเพื่อการ **ตอบสนองภัยพิบัติ, เกษตรอัจฉริยะ, การวางผังเมือง**   
- **หลักการ:** ใช้ดาวเทียมสังเกตการณ์เพื่อเก็บข้อมูลความละเอียดสูง สนับสนุนการจัดการทรัพยากรธรรมชาติและความปลอดภัยของสังคม  
- **ผลกระทบ/ประโยชน์:** แม้ล้มเหลว แต่ให้บทเรียนสำคัญแก่ทีมไทยในการพัฒนานวัตกรรมอวกาศต่อไป  

> **จุดสำคัญที่ควรจำ / Keyword:** THEOS‑2A failure → PSLV stage‑3 anomaly, 100 kg Thai‑built sat  

แหล่งข่าว: Bangkok Post, https://www.bangkokpost.com/thailand/general/3174010/launch-of-thaimade-satellite-goes-awry (12 ม.ค. 2026)

## 3. คณะรัฐมนตรีกำหนดเขตคุ้มครองสิ่งแวดล้อมเพื่อปกป้องโลมาอิรวดี `2026`
- เขตคุ้มครองครอบคลุม **สี่ตำบล** ในจังหวัดชลบุรีและฉะเชิงเทรา เพื่อลดมลพิษและปกป้อง **ป่าโกงกางและโลมาอิรวดี**  
- กิจกรรมที่ต้องมี **การตรวจสอบผลกระทบสิ่งแวดล้อม (IEE)** เช่น การก่อสร้างโรงแรม, คอนโด, ท่าเรือขนาด 100‑500 ตัน  
- การห้ามปล่อยของเสียโดยไม่ได้บำบัดและการควบคุมการก่อสร้างในโซนทะเลเป็นส่วนสำคัญของกฎระเบียบ  
- **หลักการ:** ปกป้องระบบนิเวศทางน้ำและสัตว์ทะเลที่หายากโดยการจำกัดกิจกรรมที่ก่อให้เกิดมลพิษและการทำลายที่อยู่อาศัย  
- **ผลกระทบ/ประโยชน์:** ลดการสูญเสียประชากรโลมาอิรวดี เพิ่มคุณภาพน้ำและส่งเสริมการท่องเที่ยวเชิงอนุรักษ์ในพื้นที่  

> **จุดสำคัญที่ควรจำ / Keyword:** Bang Pakong estuary protection → Irrawaddy dolphin, IEE required  

แหล่งข่าว: Thai PBS World, https://www.thaipbsworld.com/around-thailand/573237 (24 พ.ย. 2026)

## 4. ความรู้พื้นฐาน – Machine Learning (supervised / unsupervised / reinforcement) `2025` `ความรู้พื้นฐาน`
- **Supervised learning** ใช้ข้อมูลที่มีป้ายกำกับเพื่อฝึกโมเดลให้ทำนายผลลัพธ์ เช่น การจำแนกรูปภาพสัตว์  
- **Unsupervised learning** ค้นหาโครงสร้างหรือกลุ่มในข้อมูลที่ไม่มีป้ายกำกับ เช่น การจัดกลุ่มข้อมูลสุขภาพประชากร  
- **Reinforcement learning** โมเดลเรียนรู้จากการลอง‑ผิด‑ทำใหม่โดยรับรางวัลหรือการลงโทษ เช่น หุ่นยนต์ควบคุมการเดินทางในสนามแข่ง  
- การเลือกวิธีขึ้นกับ **ลักษณะของข้อมูล** และ **เป้าหมายการใช้งาน** เช่น การพยากรณ์อากาศอาจใช้ supervised, การวิเคราะห์พฤติกรรมผู้ใช้อาจใช้ unsupervised  

> **จุดสำคัญที่ควรจำ / Keyword:** Supervised → labels; Unsupervised → clusters; Reinforcement → rewards
